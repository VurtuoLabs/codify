# Codify: Instagram post

## Option A (lead with the problem)

Your knowledge base isn't out of date because nobody wrote the docs.

It's out of date because the person who fixed the thing moved on to the next
ticket, and the fix only ever existed in their head.

Codify is a Salesforce service agent that fixes that. A technician closes a case,
says how they fixed it in one sentence, and walks away. Codify writes the
resolution onto the case, tags the root cause, drafts a knowledge article, and
flags every other open case with the same cause.

One recap. Four outputs. Under a minute.

The part I'm most pleased with is what it refuses to do:

→ It will not guess a root cause. Two independent keyword matches or it declines
and asks. One passing mention of "network" is not a diagnosis.
→ It never publishes an article. Ever. It writes drafts and a human approves
them. That isn't a setting, there's no code path that could publish.
→ When it isn't sure, it says so and hands the case to a person.

A wrong root cause doesn't just mislabel one record. It pushes the wrong fix onto
everyone else's open cases. Refusing is the feature.

Full build is open source. Link in bio.

## Option B (shorter, punchier)

Built a Salesforce agent that turns "yeah I just reflashed the firmware" into a
knowledge article.

Codify. A technician closes a case and describes the fix once. It writes the
resolution to the case, tags the root cause, drafts the article, and flags every
other open case with the same cause.

Then it does the thing most AI demos skip: it refuses.

No corroboration, no root cause tag. It asks instead.
No article goes live without a human approving it. Not configurable.
Too vague to classify? It escalates rather than guessing.

Because a wrong root cause doesn't mislabel one case, it spreads the wrong fix
across everyone else's.
